This folder contains my Data Analysis projects where I explore data, uncover insights, and communicate findings through clear storytelling and visualizations.

The work in this section focuses on:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Statistical analysis and hypothesis testing
- Dashboarding and data visualization
- Business insight generation
- Reporting and recommendation writing

## Tools and Technologies

Common tools used in this track include:

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- SQL
- Excel / Google Sheets
- Power BI / Tableau
- Basic statistics and probability
