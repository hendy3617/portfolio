# Data Engineering Projects

This folder contains my Data Engineering projects focused on building reliable, scalable, and production-oriented data systems.

## Overview

Data Engineering is the backbone of data-driven applications. The projects in this section are centered around:

- Data ingestion and collection
- ETL/ELT pipeline design
- Data warehousing and modeling
- Workflow orchestration
- Data quality and validation
- Batch and streaming data processing

## Tools and Technologies

Common tools used in this track include:

- Python (Pandas, PySpark)
- SQL
- Apache Airflow
- Apache Kafka
- Spark
- dbt
- Docker
- Cloud platforms (AWS/GCP/Azure)
